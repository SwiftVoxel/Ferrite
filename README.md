# Ferrite

Ferrite is an open-source Minecraft clone written in Rust and built with Cargo.

## ℹ️ Information

Ferrite aims to be a standalone, open-source reimplementation of the Minecraft experience — not a server plugin, not a mod, and not a server software of any kind. It's a full client-side clone, covering everything from world generation and gameplay to rendering.

The project is currently console-only while core systems are being built out; rendering and windowing are planned for a later stage.

## 🚧 Project Status

**Pre-Alpha**

Ferrite is in the earliest stages of development. Core functionality is incomplete, APIs and internal structure are unstable and subject to change without notice, and there is no guarantee of backward compatibility between commits. It is not yet suitable for general use.
